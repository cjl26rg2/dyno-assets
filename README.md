# Quasar assets

Pictures for the Quasar bot on [Yapper](https://www.yapper.website): one for each command category and each automatic post ("QUASAR MODERATION", "QUASAR LOGS", "QUASAR GIVEAWAY" and so on).

The bot loads them from:

```
https://raw.githubusercontent.com/cjl26rg2/dyno-assets/main/banners/<name>.png
```

They are made by `scripts/make-banners.js` in the bot's folder. Each PNG has its SVG source next to it.

The `brand` folder has the Quasar logo (512×512) and profile banner (1500×500), as PNG and SVG.
