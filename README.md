# Dyno assets

Banner pictures for the Dyno bot on [Yapper](https://www.yapper.website): one for each command category and each automatic post ("DYNO MODERATION", "DYNO LOGS", "DYNO GIVEAWAY" and so on).

The bot loads them from:

```
https://raw.githubusercontent.com/cjl26rg2/dyno-assets/main/banners/<name>.png
```

They are made by `scripts/make-banners.js` in the bot's folder. Each PNG has its SVG source next to it.
